// How it works

What does the model do?

Every team carries an Elo rating that moves after each game and drifts a third of the way back to average each off-season. Add each team's last five games — point differential and turnover margin — plus rest, division and neutral-site flags. A logistic regression trained on 2006–2023 turns those into a home-win probability.

// Inputs

What the model sees

Six numbers per game, all known before kickoff, all home minus away.

{{ icon('chart', 14) }}Elo rating

Strength from every past result, weighted by margin of victory.

{{ icon('plusminus', 14) }}Point differential

Average margin over the last five games.

{{ icon('swap', 14) }}Turnover margin

Takeaways minus giveaways, last five games.

{{ icon('moon', 14) }}Rest days

Short weeks and byes, home minus away.

{{ icon('grid', 14) }}Division game

Rivals know each other; home edge shrinks.

{{ icon('globe', 14) }}Neutral site

International games and the Super Bowl.

{{ icon('target', 14) }}Calibrated

A 70% pick should win about 70% of the time.

{{ icon('shield', 14) }}Leak-tested

Tests prove no game sees its own future.
